# Hot Take v0.1.0-alpha.1

The first developer alpha of Hot Take: a small Go framework for building
agents with declarative skills, native tools, configured MCP connections and
explicit permissions. This is an experimental release, not a stable production
support commitment. Public APIs and configuration formats may change.

## Install

Requires Go 1.24 or later:

```sh
go install github.com/Lordeagle4/hot-take/cmd/hot-take@v0.1.0-alpha.1
hot-take --version
hot-take demo "What time is it?"
```

See the [installation guide](https://github.com/Lordeagle4/hot-take/blob/v0.1.0-alpha.1/docs/installation.md)
for PATH setup, the starter project and source builds. No prebuilt binaries are
included in this release.

## Included

- Provider-neutral Go runtime with an OpenAI Responses adapter and continuation.
- Strict JSON project/plugin manifests and Markdown skill instructions.
- Deterministic skill selection and vendor-neutral capability registration.
- Native tools and manifest-allowlisted MCP tools with namespaced registration.
- Deny-by-default CLI policy, explicit allow/deny/ask rules and skill scope enforcement.
- Ctrl+C cancellation, cancellable approvals, a default two-minute deadline and
  a cumulative 32-tool-call budget; configurable limits and model-step bounds.
- Runtime event interfaces and a deterministic offline clock demo.
- Local catalogue MCP example and regression tests for approval, denial,
  transport failure, provider continuation and cancellation.

## Compatibility and limitations

| Area | Alpha support |
| --- | --- |
| Go | 1.24 or later; automated CI runs on Linux |
| Model providers | OpenAI Responses adapter; other providers require an implementation of the Go interface |
| MCP revision | Client targets `2026-07-28` only; no legacy negotiation/fallback |
| MCP transport | Streamable HTTP with JSON or request-scoped SSE responses; no stdio |
| MCP operations | Tool discovery and execution; no resources, prompts or subscriptions |
| Authentication | Environment-supplied bearer tokens; no OAuth flow |
| Plugins | Manually configured manifests; no marketplace, automatic installation or runtime connection UI |
| Agent runs | Single-input runs; no persistent conversation store or long-term memory |
| Orchestration | Single agent; no multi-agent scheduler |
| CLI | `demo`, `run`, `--version`; no project generator or doctor command |

MCP `input_required` results stop with an explicit error. Arbitrary third-party
MCP server compatibility has not been certified. Native tools/providers must
honour context cancellation; the framework is not an execution sandbox. A
cancelled run does not undo tools that already completed.

## Validation status

Formatting, static analysis, race-enabled automated tests and builds gate this
release. The integration regression uses the actual OpenAI adapter against a
scripted local Responses endpoint and a local MCP fixture.

**The hosted-model smoke test and independent fresh-environment onboarding are
still outstanding.** No live OpenAI API key was available during preparation.
The [integration guide](https://github.com/Lordeagle4/hot-take/blob/v0.1.0-alpha.1/docs/integration.md)
provides the opt-in live test. Do not interpret green CI as hosted-model or
third-party MCP interoperability verification.
